## 1. ภาพรวม

- **Nightout.day** แพลตฟอร์มครบวงจรของการเที่ยวกลางคืน: ค้นหาร้าน · จองโต๊ะ · ชำระมัดจำ · ดูความปลอดภัย · คอมมูนิตี้/ตั้งกระทู้/หาเพื่อนเที่ยว · ช่วยร้านจัดการลูกค้าช่วงให้บริการ
- 3 ส่วน: Customer App (มือถือ) · Merchant Dashboard (เว็บ/แท็บเล็ต) · Admin & Super Admin Panel (เว็บ) — flow: จอง → จ่ายมัดจำ → สแกนเข้าร้าน → เคลียร์เงิน/คืนเงิน
- **ปัญหาลูกค้า:** งบจำกัด (200–500 บาท/คน) หาร้านตามงบไม่ได้ · รวมกลุ่มยาก เพื่อนสาย โต๊ะหลุด · หารเงินวุ่นวาย · รอคิวนาน ขาดรีวิว/อันดับที่เป็นกลาง
- **ปัญหาร้าน:** No-show สูง · คิวหน้าร้านช่วง Peak วุ่น · ยอดวันธรรมดาต่ำ
- **ปัญหาแอดมิน:** ขาดเครื่องมือคัดกรองร้าน, ตรวจ Safety, จัดการข้อพิพาท
- **กลุ่มลูกค้า:** อายุ 20+ ทุกกลุ่ม เฟสแรกเน้นนักศึกษา — หลัก "The Party Gang" 20–25 ปี กลุ่ม 2–8 คน งบ 200–350 บาท/คน มีแกนนำจอง · รอง First Jobber กลุ่ม 2–4 คน งบ 400–1,000+ บาท/คน
- **พื้นที่นำร่อง:** 1 โซนรอบมหาวิทยาลัยหอการค้าไทย แล้วขยายตามเครือข่ายพันธมิตร + content marketing
- **วัตถุประสงค์:** จัดการจองโต๊ะ + มัดจำ แก้ No-show · ช่วยคุมงบ · สร้างพฤติกรรมจ่ายล่วงหน้า · ลิงก์หารค่าใช้จ่ายให้กลุ่ม (ผู้จองจ่ายคนเดียว) · เก็บข้อมูลพฤติกรรมเพื่อต่อยอด

## 3. กฎที่ใช้ทั้งระบบ

| กฎ | โค้ด |
|---|---|
| ยืนยันอายุ 20+ ตอนสมัคร + ยอมรับ ToS + PDPA Consent ก่อนใช้งาน · ขอ consent ก่อนนำข้อมูลการจอง/พฤติกรรมไปใช้ต่อ | ✅ |
| เงินที่จ่ายผ่านแอปเรียกว่า **"ค่าธรรมเนียมจองโต๊ะ (Table Fee)"** เท่านั้น · ทุกการจองจ่ายเฉพาะมัดจำโต๊ะ | 🔧 ถ้อยคำ |
| ห้ามขาย/พรีออเดอร์แอลกอฮอล์ผ่านแอป · ห้ามคำว่า "ขายเหล้า/เบียร์" ในแอปและแคมเปญ · ขายแอลกอฮอล์โดยตรงอยู่นอกขอบเขต | ✅ |
| โปรของร้านต้องไม่ใช่แอลกอฮอล์ (มิกเซอร์, อาหาร, น้ำแข็ง, ส่วนลดวันเกิด) ห้ามลด/แถมแอลกอฮอล์ (ม.30) | 🔧 ตัวอย่าง "โปรเบียร์ก่อน 2 ทุ่ม" ใน `merchant/promotions` + seed ต้องเปลี่ยน |
| ชำระผ่าน **Beam Payment แบบ Escrow** · ผู้จองจ่ายยอดรวมคนเดียว (ไม่มี Split-Pay) · **ไม่มีโอน + แนบสลิป** | 🔧 โค้ดตอนนี้ยังเป็น PromptPay ของ NightOut + อัปโหลดสลิป + แอดมินตรวจ (DRAFT ห้ามรับเงินจริง) → ต้องเปลี่ยนเป็น Beam และเลิกใช้ flow สลิปทั้งหมด |
| ต้องติ๊กยอมรับ Refund Policy (ริบมัดจำเมื่อสาย 30 นาที) ก่อนชำระทุกครั้ง | ✅ (`booking_deposit_consents`) |
| แจ้งเตือนลูกค้าก่อนเวลาจอง 15 นาที · ใกล้หมดเวลากด **"ขอต่อเวลา 15 นาที" ได้ 1 ครั้ง** | 🆕 |
| เช็กอินสำเร็จเมื่อ **สมาชิกคนแรก** ของกลุ่มสแกน QR · ต้องสแกน QR ผูก **Timestamp ของ server กลาง** เท่านั้น (กันข้อพิพาท "มาตรงเวลาแต่พนักงานไม่กด") | 🔧 |
| สายเกินเวลา → ระบบปลดโต๊ะอัตโนมัติ (**Forfeited**) ร้านยึดมัดจำ 100% | 🔧 ตอนนี้ NO_SHOW ตาม grace ที่ร้านตั้ง |
| ยกเลิก/คืนเงิน: **โต๊ะทั่วไป** ยกเลิกก่อน ≥ 6 ชม. คืนเต็ม · **กลุ่ม (Party Set)** ก่อน ≥ 24 ชม. คืนเต็ม · หลังจากนั้นริบ · มัดจำประมาณ 200–300 บาท/คน | 🔧 ตอนนี้ร้านตั้ง `refund_before_hours` เอง · Party Set ใน `PARTY_SET.md` อัปเดตแล้ว (ยังไม่ทำในโค้ด) |
| ร้านรับจองแล้วไม่มีโต๊ะให้ → คืนมัดจำลูกค้า + ติด **Blacklist** ร้าน (ปรับเงินไม่ได้) | 🆕 |
| ป้าย Safety: **"ข้อมูลอ้างอิงจากร้านค้า (Merchant Declared)"** + วันที่ตรวจล่าสุด + disclaimer · ห้ามคำว่า "Safety Verified" | 🔧 ตอนนี้ "ยืนยันโดย NightOut" (`ui/components/safetyList.tsx`, `merchant/safety`) |
| จ่ายโปรโมท/โฆษณาไม่มีผลต่อดาวและอันดับ · ร้านที่โปรโมทติดป้าย "แนะนำ · โฆษณา" เสมอ | ✅ |
| โครงสร้าง DB / System Settings แก้ผ่าน migration โดยทีม Tech เท่านั้น ไม่เปิดแก้ใน Admin UI | ✅ |

## Phase 1 — Legal-Proof MVP & Manual Validation

- **ช่วง:** เดือน 1–3 (เริ่มกลาง ต.ค. 2026 · Soft Launch สิ้น Sprint 6 ม.ค. 2027) · รับมัดจำผ่าน Beam Payment แบบ Escrow · ฟรีทั้งลูกค้าและร้าน · DB ต้องยืดหยุ่นพอเปลี่ยนเป็น API automation
- **KPI:** ร้าน Active 5–10 ร้าน · MAU 10,000 · ออก E-Ticket อัตโนมัติทันทีเมื่อจ่ายผ่าน Beam สำเร็จ · No-show < 5% · ใช้ลิงก์หารเงิน > 50% ของการจอง

### ชุมชน (Community) — Phase 1 · นอก MVP อนุมัติ 2026-10-11 · 🆕

- **ลูกค้า:** ฟีดกระทู้ 6 หมวด (ดนตรีสด · รีวิว · หาเพื่อนเที่ยว · เครื่องดื่ม · ถาม-ตอบ · ประกาศ) เรียงล่าสุด/ยอดนิยม/ยังไม่มีคำตอบ ค้นหาได้ · ตั้งกระทู้แท็กร้านได้ 1 ร้าน · แนบรูป/วิดีโอ ≤ 6 ไฟล์ (วิดีโอ ≤ 30 วิ) · ตอบซ้อนได้ 1 ชั้น · ถูกใจ · บันทึกไว้อ่าน · ปักหมุดส่วนตัว ≤ 3 (เห็นคนเดียว) · ร่างบันทึกอัตโนมัติเก็บ 7 วัน · แก้/ลบได้เฉพาะของตัวเอง · รายงานกระทู้/ความเห็นได้ · หมวด "ประกาศ" ตั้งได้เฉพาะทีม NightOut
  - สิทธิ์: อ่าน = ทุกคน (guest ได้) · ตั้ง/ตอบ/ถูกใจ/บันทึก/ปักหมุด/รายงาน = ลูกค้าที่ล็อกอิน · บัญชีที่ถูกแบนอ่านได้อย่างเดียว
- **ทีมร้าน (ทุกบทบาท):** ทุกโพสต์/คอมเมนต์มีป้าย "ทีมร้าน · <ชื่อร้าน>" (รวมตอนใช้บัญชีส่วนตัว) · คอมเมนต์/ตอบได้ทุกกระทู้ · ตั้งกระทู้ได้เฉพาะหมวด **"ข่าวจากร้าน"** ต้องแท็กร้านตัวเอง ≤ 3 กระทู้/ร้าน/สัปดาห์ · กระทู้ที่ทีมร้านตั้งแท็กร้านตัวเอง และการถูกใจของทีมร้านในกระทู้ที่แท็กร้านตัวเอง **ไม่นับ** "ร้านมาแรง" และยอดถูกใจ · ห้ามโปรแอลกอฮอล์ (ม.30/32) และห้ามพูดถึงร้านอื่นในทางเสีย
- **แอดมิน (`/community`):** ดูกระทู้/ความเห็นทั้งหมด + รายงานที่ค้าง · ซ่อน / ลบ / แสดงอีกครั้ง / ปิดรายงาน (บันทึก Audit Log + แจ้งเจ้าของพร้อมเหตุผล) · ตั้งหมวด "ประกาศ" (ป้าย "ทีม NightOut") · ไม่มีปักหมุดรวม · ตรวจโพสต์ทีมร้านที่อาจโฆษณาแอลกอฮอล์/โจมตีร้านอื่น · Inspector ไม่มีสิทธิ์จัดการ · ประวัติการจัดการดูได้ใน Audit Log (Super Admin)
- เริ่มเขียนโค้ดเมื่อไร: เพิ่มโดเมน `community` ตาม ADR 0006 + `docs/STRUCTURE.md` + `docs/SITEMAP.md` ในงานเดียวกัน

## Phase 2 — Payment Automation & Monetization (เดือน 4–6)

- **เป้าหมาย:** จ่ายอัตโนมัติ 100% ผ่าน **Beam Payment** (ต่อจาก Phase 1) · เริ่มเก็บ GP 5–7% · ขยายโซนที่ 2 (ทองหล่อ / เอกมัย / อารีย์) และกลุ่ม First Jobber
- **KPI:** MAU 25,000+ · จ่ายผ่าน API สำเร็จ > 95% · รายได้ GP โต ≥ 20%/เดือน · เลือก Fast-Track > 15%

| ฝั่ง | ฟีเจอร์ | รายละเอียด | โค้ด |
