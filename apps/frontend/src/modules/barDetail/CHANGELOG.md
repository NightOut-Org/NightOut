## 2026-10-16 — จองตอนยังไม่ล็อกอิน อยู่หน้าเดิม
- กด "จองเลย" / "จองโต๊ะ" (รวมในลิ้นชักประเมินราคา) ตอนยังไม่ล็อกอิน = เปิด modal เข้าสู่ระบบบนหน้าร้านเลย (ลิ้นชักและรายการที่เลือกยังอยู่) ล็อกอินแล้วไปหน้าจอง — เดิมเด้งไปหน้าแรก ปิด modal แล้วหลุดจากร้าน
- ลิงก์ไปหน้าที่ต้องล็อกอินจากหน้าอื่น (การ์ดหน้าแรก แผนที่ ชุมชน …): `RequireAuth` (`router/middleware.tsx`) ย้อนกลับหน้าเดิมแล้วเปิด modal · เปิด URL ตรง = `/login?next=…` เหมือนเดิม
- ไฟล์: `page.tsx` · `router/middleware.tsx`


## 2026-10-13 — ดีลวันนี้
- ส่วนโปรโมชันเปลี่ยนเป็น "ดีลวันนี้" แสดงเฉพาะโปรที่ใช้ได้วันนี้ (วันตามเวลากรุงเทพ) · เลย cutoff = จางลง "หมดเวลาวันนี้" · โปรวันอื่นบอกแค่จำนวน · ร้านปิดวันนี้ = บอกว่าร้านปิด · โปรที่ปิด/รอตรวจ/ถูกปฏิเสธ/หมดอายุไม่แสดง แม้ทีมร้านเปิดดูเอง
- ไฟล์: `page.tsx`, `components/promotionList.tsx`, `ui/utils/promotion.ts`, `services/barsRepo.ts`

## 2026-10-13 — ป้าย Safety แยกวิธีตรวจ
- แท็บความปลอดภัย (`ui/components/safetyList.tsx`): ข้อที่ทีมงานตรวจแล้วแสดง "ทีมงานลงพื้นที่ตรวจ <วันที่>" (ON_SITE) หรือ "ตรวจหลักฐานแล้ว <วันที่>" (EVIDENCE · ข้อมูลเก่าที่ไม่รู้วิธี = ตรวจหลักฐาน) · หัวการ์ด "ทีมงานลงพื้นที่ตรวจล่าสุด <วันที่>" นับเฉพาะการลงพื้นที่ + "ตรวจหลักฐานแล้วล่าสุด <วันที่>" แยกบรรทัด · ยังคง "ข้อมูลอ้างอิงจากร้านค้า (Merchant Declared)" + ข้อความปฏิเสธความรับผิด
- ข้อมูล: `safety[].verify_method` จาก view `bar_detail` (migration `…20261013000800`) → `verifyMethod` ใน `services/barsRepo.ts`
