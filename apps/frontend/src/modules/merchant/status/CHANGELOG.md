## 2026-10-21 — รีดีไซน์หน้าสถานะการตรวจร้านเป็นเส้นเวลา 3 ขั้น (ตามแบบที่เจ้าของส่งมา)
- เลิกใช้แพทเทิร์นสำเร็จรูปเดิม (ป้ายเหนือหัวข้อ · การ์ด 5 ใบหน้าตาเดียวกันพร้อมแถบ progress · ภาพแทนสีเทาครึ่งจอ)
- หัวข้อ = ชื่อร้าน + สถานะ และบรรทัด "3 ขั้นก่อนลูกค้าจองได้ คุณอยู่ขั้นที่ N" · เส้นเวลาแนวตั้ง: ส่งข้อมูลแล้ว (ทอง + ถูก) → ทีมกำลังตรวจ (วงทองมีแสง) → ลูกค้าเห็นร้านและจองได้ (ตัวเลข)
- ขั้นที่ 2 มีแผง "ระหว่างรอ ช่วยให้ลูกค้าเลือกร้านคุณ": ข้อมูลร้าน · เมนูและราคา · ความปลอดภัย บอกสิ่งที่ขาดจริงจากข้อมูลร้าน + ลิงก์สีทอง (เติม / เพิ่มเมนู / กรอก)
- ขั้นที่ 3 มีแผงขอบประสีทอง: ตำแหน่งร้าน · โซนและโต๊ะ (ยังไม่ทำ = ไอคอนเตือน ข้อความทอง ปุ่มทอง "เพิ่มโซน" · ครบ = ถูกสีเขียว + ลิงก์ "ดู") · อนุมัติแล้ว = ขั้น 3 เป็นขั้นปัจจุบันจนกว่าจะครบ แล้วแผงระหว่างรอย้ายมาใต้ขั้น 3
- คอลัมน์ขวา (sticky) "การ์ดที่ลูกค้าจะเห็นหลังอนุมัติ" จากข้อมูลจริง (ไม่มีรูปปก = บอกตรงๆ + ลิงก์เพิ่มรูป) · พื้นที่ "ทองหล่อ, วัฒนา" (ร้านที่ยังไม่แสดงขอเขต/อำเภอจาก `GET /public/area` · `api.ts` ใหม่) · มือถือการ์ดอยู่หลังเส้นเวลา
- ไฟล์: `page.tsx` · `api.ts`
