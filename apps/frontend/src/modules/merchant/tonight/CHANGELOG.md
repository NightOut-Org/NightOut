## 2026-10-13 — ปลดโต๊ะ (Forfeited) · ป้ายต่อเวลา
- เตือน "เลยเวลา N โต๊ะ · ปลดโต๊ะใน X นาที" (เดิม "ยกเลิกอัตโนมัติ") นับจาก `auto_cancel_at` จริง (grace ของร้าน + เวลาที่ลูกค้าต่อ)
