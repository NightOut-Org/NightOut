## 2026-10-13 — ตำแหน่งร้าน (หมุด) + แอดมินตรวจหมุด
- สมัคร 4 ขั้น: ข้อมูลร้าน → **ตำแหน่งร้าน** (ปักหมุดในไทย บังคับ + ที่อยู่ ที่จอดรถ รถไฟฟ้าใกล้สุด · ย้ายช่องที่อยู่มาจากขั้นแรก) → เอกสาร → ส่งตรวจ (สรุปเพิ่มพิกัด / รถไฟฟ้า / ที่จอดรถ + แผนที่ย่อ) · ทีม NightOut ตรวจหมุดพร้อมการอนุมัติร้าน
- แผนที่ mount ตอนถึงขั้นตำแหน่งร้าน (ไม่สร้างไว้ใน div ที่ซ่อน) · ส่ง `POST /merchant/join` พร้อม `lat` / `lng` / `parking_note` / `transit_*`
- `api.ts` + `searchPlace` / `reversePlace` (`GET /geocode/*` — ประกาศซ้ำกับ `merchant/location` ตาม ADR 0007)
- ไฟล์หลัก: `page.tsx`, `api.ts`
