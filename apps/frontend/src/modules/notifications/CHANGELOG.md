# CHANGELOG — frontend/modules/notifications

## 2026-10-21 — แจ้งเตือนของร้านอื่นโผล่ในโหมดร้าน
- เดิมโหมดร้านแยกแจ้งเตือนจากลิงก์ `/merchant…` อย่างเดียว ไม่ดูว่าเป็นของร้านไหน → แจ้งเตือนเก่าจากร้านที่เคยอยู่ทีมแล้วถูกถอด/ย้ายเจ้าของ หรือร้านที่สองของบัญชี โผล่ในกล่องของร้านที่จัดการอยู่
- ตอนนี้โหมดร้าน (หน้า `/notifications?view=merchant` และกระดิ่งบน navbar) แสดงเฉพาะแจ้งเตือนที่ `barId` ตรงกับร้านของโหมดร้าน (`user.barId`) · เลขบนกระดิ่งนับแบบเดียวกัน
- ไฟล์: `page.tsx` · `ui/utils/notifications.ts` (`notificationsForView`) · `ui/components/navbar.tsx` · `services/mappers/account.ts` · `services/models.ts`

## 2026-10-16 — แยกแจ้งเตือนร้าน / ลูกค้า

- ปุ่ม "อ่านทั้งหมดแล้ว" อ่านเฉพาะรายการในโหมดที่เห็น (ส่ง `ids`) · ลบ `markAllRead` ที่ไม่ใช้แล้ว

## 2026-10-14 — กดดูแจ้งเตือนแล้วอ่านเฉพาะอันนั้น
- กดแจ้งเตือนในกล่องกระดิ่ง (navbar) หรือกดชื่อแจ้งเตือนที่มีลิงก์ในหน้า `/notifications` → ส่ง `POST /me/notifications/read` พร้อม `ids` = อันที่กด · เลขบนกระดิ่งลด 1 และจุดแดงของอันนั้นหายทันที (navbar อัปเดตก่อนรอ store) · ส่งไม่สำเร็จ = กลับเป็นยังไม่อ่าน + แจ้ง error
- เปิดกล่องกระดิ่งเฉย ๆ ไม่ถือว่าอ่าน · แจ้งเตือนที่ไม่มีลิงก์ยังใช้ปุ่ม "อ่านทั้งหมดแล้ว"
- เพิ่ม `markRead(ids)` ใน `api.ts` · ไฟล์: `ui/components/navbar.tsx`, `page.tsx`, `api.ts`
