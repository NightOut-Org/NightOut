## 2026-10-13 — ชุมชน: สิทธิ์ทีมร้าน (ป้ายทีมร้าน · ข่าวจากร้าน · ไม่นับไลก์/ร้านมาแรง)
- ทีมร้าน (ทุกบทบาท): ตั้งกระทู้ใหม่ได้เฉพาะหมวด "ข่าวจากร้าน" (ล็อกหมวด + แถบแจ้ง) · เลือกได้เฉพาะร้านตัวเอง พร้อม "โพสต์แล้ว N/3" · ครบโควตา/ร้านถูกระงับ = เลือกไม่ได้ (บอกเวลาโพสต์ได้อีก · ข้อความตัวเลือกขึ้นบรรทัดใหม่ได้บนมือถือ) · กล่อง "ก่อนโพสต์" ของข่าวจากร้าน (≤ 3 กระทู้/7 วัน · ห้ามโปรแอลกอฮอล์ ม.30/32 · ห้ามพูดถึงร้านอื่นในทางเสีย · ป้ายทีมร้าน)
- ทุกร้านในทีมถูกระงับ = ตั้งกระทู้ใหม่ไม่ได้ชั่วคราว (มีข้อความบอก) · ลูกค้าทั่วไปเลือกหมวดข่าวจากร้านไม่ได้ (`?category=shop-news` / ร่างเดิมถูกล้างหมวด)
- แก้กระทู้: ข่าวจากร้านเปลี่ยนหมวด/ร้านไม่ได้ (แก้ได้เฉพาะทีมของร้านที่แท็กซึ่งแสดงอยู่) · ทีมร้านแก้กระทู้เก่าในหมวดเดิมได้ แต่แท็กร้านตัวเองเพิ่มไม่ได้ · ร่างแก้ที่ค้างจากก่อนเข้าทีมถูกปรับกลับเป็นหมวด/ร้านของกระทู้เดิม
- ไฟล์: `page.tsx` · `api.ts` (`useMyCommunityTeam` → `GET /me/community/team`)

## 2026-10-11 — ชุมชน: แนบรูป/วิดีโอในกระทู้และความเห็น
- หัวฟอร์ม (จอใหญ่): ย้าย "บันทึกร่างอัตโนมัติ" ไปมุมขวา และใช้ช่องเดียวกับสถานะร่าง (กำลังบันทึก… / บันทึกร่างแล้ว HH:MM / ออฟไลน์ / ไม่สำเร็จ)
- ช่อง "รูปภาพ / วิดีโอ" สูงสุด 6 ไฟล์ — อัปโหลดเข้า `community-media` ทันทีที่เลือก (รูปย่อก่อน · วิดีโอมีภาพปก) · ร่างเก็บ path ไว้ เปิดจากเครื่องอื่นเห็นภาพย่อ (signed URL) · ระหว่างอัปโหลดกดโพสต์ไม่ได้ · แก้กระทู้ = แทนที่ไฟล์ทั้งชุด
- ไฟล์: `page.tsx` · ของกลาง `ui/components/communityMediaPicker.tsx`
