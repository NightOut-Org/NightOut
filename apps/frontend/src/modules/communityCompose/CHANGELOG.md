# CHANGELOG — frontend · communityCompose

## 2026-10-11 — ชุมชน: แนบรูป/วิดีโอในกระทู้และความเห็น
- หัวฟอร์ม (จอใหญ่): ย้าย "บันทึกร่างอัตโนมัติ" ไปมุมขวา และใช้ช่องเดียวกับสถานะร่าง (กำลังบันทึก… / บันทึกร่างแล้ว HH:MM / ออฟไลน์ / ไม่สำเร็จ)
- ช่อง "รูปภาพ / วิดีโอ" สูงสุด 6 ไฟล์ — อัปโหลดเข้า `community-media` ทันทีที่เลือก (รูปย่อก่อน · วิดีโอมีภาพปก) · ร่างเก็บ path ไว้ เปิดจากเครื่องอื่นเห็นภาพย่อ (signed URL) · ระหว่างอัปโหลดกดโพสต์ไม่ได้ · แก้กระทู้ = แทนที่ไฟล์ทั้งชุด
- ไฟล์: `page.tsx` · ของกลาง `ui/components/communityMediaPicker.tsx`

## 2026-10-10 — ชุมชน: ปักหมุดส่วนตัว + ฉบับร่างเก็บที่ backend
