## 2026-10-12 — ชุมชน: แก้ไขความเห็น + ประวัติการแก้ไข
- ความเห็นของฉันมีปุ่ม "แก้ไข" → แก้ในกล่องความเห็นเดิม ทั้งข้อความและรูป/วิดีโอ แล้วกด "บันทึก" ครั้งเดียว (ปุ่มบันทึกปิดเมื่อไม่มีอะไรเปลี่ยน/ไฟล์ยังอัปโหลดไม่เสร็จ · ทั้งฟอร์ม disabled ระหว่างบันทึก · พลาด = คงที่แก้ไว้) · Ctrl+Enter บันทึก · Esc ยกเลิก
- ร่างแก้ความเห็น (EDIT_COMMENT) บันทึกที่ backend อัตโนมัติ เปิดแก้ใหม่ได้ร่างเดิม ("กลับไปใช้ข้อความเดิม") · ยกเลิก = ทิ้งร่าง และ backend ลบไฟล์ที่เลือกแต่ไม่ได้ใช้
- กระทู้/ความเห็นที่แก้แล้วมีป้าย "แก้ไขแล้ว" (tooltip เวลาแก้ล่าสุด) กดแล้วเปิดประวัติการแก้ไขทุกเวอร์ชัน ใหม่สุดก่อน พร้อมไฟล์แนบของแต่ละเวอร์ชัน (ทุกคนดูได้)
- ไฟล์: `components/commentEditor.tsx` (ใหม่) · `components/historyModal.tsx` (ใหม่) · `components/commentList.tsx` · `page.tsx` · `api.ts` (`updateComment` · `useHistory` · `saveCommentEditDraft` · `deleteCommentEditDraft`)
