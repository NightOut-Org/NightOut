# CHANGELOG — admin · community

## 2026-10-21 — เลิกใช้ " · " คั่นข้อความที่ผู้ใช้เห็น (ส่วนที่เหลือ)
- ข้อความในหน้า (หัวข้อ Drawer คำอธิบาย ป้าย ข้อความสำเร็จ) เปลี่ยนจากต่อด้วย " · " เป็นประโยค วงเล็บ หรือคำเชื่อม (และ / โดย / เมื่อ) · ชื่อ + จำนวนคน = "สมชาย (4 คน)" · ไม่เปลี่ยนพฤติกรรม
- ไฟล์: หน้าและคอมโพเนนต์ในโมดูลนี้ที่เคยมี " · " ในข้อความ

## 2026-10-13 — ชุมชน: สิทธิ์ทีมร้าน (ป้ายทีมร้าน · ข่าวจากร้าน · ไม่นับไลก์/ร้านมาแรง)
- คอลัมน์ผู้เขียนมีป้าย "ทีมร้าน · <ชื่อร้าน>" (`team_bar`) · "+N ทีมร้าน (ไม่นับ)" ใต้ยอดถูกใจ (`excluded_like_count`) ทั้งกระทู้และความเห็น
- แท็บใหม่ "โพสต์ทีมร้าน" (กระทู้ + ความเห็นของทีมร้านที่ยังแสดงอยู่) พร้อมคำเตือนตรวจโปรแอลกอฮอล์ (ม.30/32) และการพูดถึงร้านอื่นในทางเสีย
- ซ่อน/ลบต้องเลือกเหตุผล (API บังคับ) ผ่าน `components/moderateModal.tsx` (ใหม่ · แทน Popconfirm) — เหตุผลส่งถึงเจ้าของโพสต์ในแจ้งเตือน · "อื่น ๆ" ต้องพิมพ์รายละเอียด · หัวข้อ/ปุ่มไม่เปลี่ยนระหว่าง modal กำลังปิด
- ป้ายเหตุผลรายงาน `ui/utils/labels.ts` (`COMMUNITY_REPORT_REASON`): "โฆษณาแฝง / โปรแอลกอฮอล์" · "ไม่สุภาพ / ให้ร้ายร้านอื่น" ให้ตรงกับหน้าบ้าน
- ไฟล์: `page.tsx` · `components/moderateModal.tsx` · `ui/utils/labels.ts`

## 2026-10-12 — ชุมชน: แก้ตารางเพี้ยน (หัวคอลัมน์ "กระทู้" ตัดทีละตัวอักษร)

- ไฟล์: `page.tsx`
